プライバシーポリシー

sunrise は作者本人だけが使う家計のアプリです。

  • Google アカウントの Gmail を読み取り専用（gmail.readonly）で読み、カード会社と銀行の利用のお知らせのメールから、日時・店名・金額を取り出します。
  • 取り出したデータは作者の自宅のコンピューターにだけ保存し、第三者に渡したり、売ったり、広告に使ったりしません。
  • メールの送信・削除・変更はしません。
  • Google から受け取ったデータの使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

Privacy Policy

sunrise is a personal budgeting app used only by its author.

  • It reads the author's Gmail with read-only access (gmail.readonly) and extracts the date, merchant and amount from card and bank notification emails.
  • The extracted data is stored only on the author's own computer at home. It is never shared with, sold to, or used for advertising by any third party.
  • It never sends, deletes or modifies email.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
